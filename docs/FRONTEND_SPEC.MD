# FRONTEND_SPECIFICATION.md
## Standart Reserve — Спецификация интерфейса

---

## 1. ОБЩИЕ ПРИНЦИПЫ

### 1.1. Технологии

| Компонент | Технология | Причина |
|-----------|------------|---------|
| **Фреймворк** | React 18+ | Универсальность, экосистема |
| **Сборка** | Vite | Быстрая разработка, горячая перезагрузка |
| **Стейт-менеджмент** | Pinia | Простота, типизация, DevTools |
| **Роутинг** | React Router v6 | Навигация по страницам |
| **UI-библиотека** | Ant Design / MUI / shadcn/ui | Богатые компоненты, таблицы, формы |
| **HTTP-клиент** | Axios + React Query | Кеширование, рефетчинг, обработка ошибок |
| **Типизация** | TypeScript + OpenAPI-генерация | Безопасность, авто-дополнение |

### 1.2. Роли и страницы

| Роль | Доступные страницы |
|------|-------------------|
| **Все (авторизованные)** | Вход, профиль |
| **Guest (наблюдатель)** | Дашборд (только чтение), Нормативы (только чтение), Справочники |
| **Commercial** | Мои запросы, Создать запрос, Карточка запроса |
| **PP** | Согласование (ПП), Все запросы, Карточка запроса |
| **Economist** | Согласование (экономист), Все запросы, Карточка запроса |
| **Logistics** | Дашборд логиста (нормативы + разовые), Управление остатками |

text

**Компоненты:**

1. **Переключатель единиц измерения** (глобальный для дашборда):
   - `шт` — показываем всё в штуках
   - `тонны` — пересчитываем через `weight_kg` (1 т = 1000 кг, делим на вес единицы)

2. **Переключатель фильтрации запасов:**
   - `Все запасы` — показываем все товары на складе
   - `Только с нормативами` — показываем только те товары, на которые есть активный норматив
   - `Требуют пополнения` — показываем только товары с дефицитом (норматив > факт)

3. **Группировка по складам** — только те склады, где есть позиции с дефицитом (при фильтре "Требуют пополнения") или все склады с нормативами.

4. **Таблица с двумя строками** — в штуках и тоннах (если выбран режим показа "шт", то тонны показываем как дополнительную информацию; если выбран режим "тонны" — наоборот).

**Кнопки управления (только pp, economist, logistics):**
- **Выгрузить шаблон** — скачивает Excel с шапкой колонок
- **Загрузить из Excel** — модалка загрузки
- **Редактировать** — карандаш в строке (не путать с переходом в карточку)

**Модалка «Загрузить продукты»:**
- Drag-and-Drop зона или кнопка «Выбрать файл» (.xlsx / .xls)
- Индикатор прогресса во время запроса
- После ответа: отчёт «Загружено X, ошибок Y» и список ошибок по строкам

**Модалка «Редактировать продукт»:**
- `code` — только чтение
- Поля: name, category (A/B/C), is_active, weight_kg, gtin (13 цифр), mark_control
- Select заводов: plant_id, second_plant_id, third_plant_id (objects type=plant)
- parent_code, children_code — автокомплит по справочнику продуктов
- Блок «Последнее изменение»: ФИО + дата (только чтение)
- Кнопки: Сохранить, Удалить (Popconfirm). Удаление блокируется на бэке при связях

**Компоненты:**
- Вкладки (Продукты, Объекты, Пользователи)
- Поиск и фильтры
- Таблица (GTIN, Честный знак, Дата изменения)
- Кнопки шаблона / загрузки / редактирования по роли

8. ПЕРЕСЧЕТ ЕДИНИЦ (шт ↔ т)
Формула:

text
1 т = 1000 кг
Вес единицы = products.weight_kg (кг)
Количество в тоннах = (Количество в штуках × weight_kg) / 1000
Пример:

text
Подшипник 6204ZZ: weight_kg = 0.25 кг
1000 шт = (1000 × 0.25) / 1000 = 0.25 т
Отображение в таблице (две строки или две колонки):

Если выбраны шт:

text
┌──────────┬────────────┬───────────┬────────────┬───────────┐

│          │ 0.25 т     │ 0.15 т    │ 0.10 т     │ т         │

text
